Live

The problem
14+ emails arrive daily. Most are noise — newsletters, LinkedIn pings, bank alerts. The 1–3 that actually need a reply were buried in the same inbox as 400+ others. Every day I had to manually triage to find them. That's 15–20 minutes of attention tax, 7 days a week.
What I built
A cloud n8n workflow that fetches the last 24 hours of email, runs each message through Claude Haiku to categorize it, passes anything urgent or reply-needed to a Claude Sonnet drafter agent that creates a Gmail draft in my voice, then sends a Slack DM summary with one-click links to each draft.
n8n Cloud Gmail OAuth2 Slack OAuth2 No laptop required
1.5–2 hours reclaimed per week. The workflow runs entirely in the cloud — no open laptop, no manual triage. The only thing I do is glance at a Slack DM and decide whether each draft is ready to send.

Categorization Logic
Claude Haiku reads each email's sender, subject, and cleaned body, then assigns one of four buckets:

URGENT_REPLY — Needs a response within 24 hours. Time-sensitive asks, direct questions from real people, anything with a deadline attached. These always go to the drafter.

REPLY_NEEDED — Real person, real ask, not on fire. Follow-ups, scheduling, non-urgent questions. These also go to the drafter.

INFORMATIONAL — Worth knowing but no reply needed. Receipts, confirmations, calendar invites, newsletters you actually want. Logged in the Slack summary but no draft created.

NOISE — Dropped silently. Promotional email, LinkedIn notifications, marketing, automated digests. Never surfaces.

Only URGENT_REPLY and REPLY_NEEDED emails advance to the Sonnet drafter. The Slack DM flags URGENT emails with a 🔴 and REPLY_NEEDED with 🟡, each with a one-click link directly to the Gmail draft.

How to Deploy
1. Set up n8n Cloud — Create an account at n8n.io. Use the cloud-hosted version so the workflow runs on a schedule without your laptop.

2. Connect Gmail — Add a Gmail OAuth2 credential in n8n. Authorize access to read messages and create drafts.

3. Add your Anthropic API key — In n8n credentials, add a new "Anthropic" credential with your API key. This powers both the Haiku categorizer and Sonnet drafter nodes.

4. Connect Slack — Add a Slack OAuth2 credential. Authorize the bot to send DMs to your workspace. Note your Slack user ID for the DM target.

5. Set the schedule — Configure the Schedule Trigger node for your preferred time (default: 4:00 pm daily). Set the Gmail node to fetch messages from the last 24 hours.

6. Paste the system prompts below into the respective AI nodes.

7. Activate — Toggle the workflow to Active. It will run on schedule with no further input required.
Email Categorizer System Prompt (Haiku node)
You are an email triage assistant. Your job is to categorize each email into one of the following buckets: 1. URGENT_REPLY — Requires a response within 24 hours (e.g., time-sensitive requests, deadlines, direct questions from real people who expect a reply today). 2. REPLY_NEEDED — Requires a response but not urgent (e.g., follow-ups, scheduling, non-time-sensitive asks from real people). 3. INFORMATIONAL — Worth knowing but no response needed (e.g., receipts, confirmations, calendar invites, newsletters you opted into). 4. NOISE — Promotional, automated, irrelevant, or low-value (e.g., marketing emails, LinkedIn notifications, digest newsletters, bank alerts with no action required). Rules: - If the sender is a real person (not a no-reply address or mailing list) and they asked a direct question, default to REPLY_NEEDED or higher. - Newsletters and digests are always INFORMATIONAL or NOISE — never URGENT_REPLY. - When in doubt between INFORMATIONAL and NOISE, prefer NOISE. For each email, respond with ONLY a valid JSON object on a single line: {"category": "URGENT_REPLY", "reason": "one sentence explaining why"} Valid category values: URGENT_REPLY, REPLY_NEEDED, INFORMATIONAL, NOISE
